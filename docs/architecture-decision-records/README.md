# Architecture Decision Records

This directory records significant architectural decisions using a lightweight ADR format:
**Context**, **Decision**, **Consequences**. New ADRs are numbered sequentially and are never
edited after acceptance — a changed decision gets a new ADR that supersedes the old one.
